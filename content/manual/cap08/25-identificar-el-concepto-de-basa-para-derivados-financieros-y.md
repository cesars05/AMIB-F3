Base para Derivados Financieros

Es la DIFERENCIA ENTRE El PRECIO DEL FUTURO Y EL PRECIO DEL MERCADO DE UN ACTIVO DETERMINADO PARA UNA FECHA DETERMINADA. La base puede ser positiva o negativa, dependiendo de si el precio del futuro es mayor o menor que el precio del contado.
