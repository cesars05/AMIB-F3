Rendimiento Para determinar el rendimiento efectivo de una acción utilizamos: Efectivo Formula: :26TEFEC=(VFIN=VIN1-1) x 100 Donde: %TEFEC — Tasa efectiva VEIN — Valor Final VINI — Valor Inicial

Ejemplo:

Un inversionista compró acciones de una emisora cuya cotización en la BMY era de 526.74 y después

de 210 días decidió venderlas cuando el precio de las acciones estaba en $28.62. ¿Cuál fue el rendimiento efectivo y anualizado para este inversionista?

Identificamos Variables %TEFEC =¿? VFIN = 28.62 VINI = 25.74

Rendimiento efectivo Sustituimos datos = (28.62 / 26.74) -1 x 100 = 7.030665%
